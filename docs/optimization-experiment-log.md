# 优化实验与消融记录

> 最后更新：2026-07-23
> 本轮对比基线：`wz-arm` / `d6ca1db`
> README 只描述当前能力；已撤销的专项方案仅在本文 E 类中留档。

## 1. 目的和判定规则

本文档记录每个优化候选的实现完整性、正确性、性能证据、合规性和最终去留，避免将“原型实现失败”误判为“优化方向无效”。

状态定义：

- **A－有效并保留**：优化模式下通过 60 项 performance 正确性；在官方 FPGA 上存在真实执行时间收益，或在明确采用本地复现时由同一 Docker/QEMU 的程序内部计时完成正反顺序重复消融；触发条件通用合规。只有改动影响未优化路径或公共前端/语义代码时，才额外要求 140 项 correctness。
- **B－实现完整但退化**：语义和边界处理完整，也完成了足够的消融，但当前降级策略或成本模型导致性能退化。否定的是当前实现，不是整个优化方向。
- **C－实现完整但未命中**：规则本身完整，但当前 60 个性能程序没有出现该 IR/MIR 形态。这只能证明当前收益为零，不能证明方向无效。
- **D－实现或实验不完整**：只实现了子集、缺少关键 fallback/成本模型，或只做了少量编译筛查而没有完整回归。不得用这类结果判定优化思路无效。
- **E－违规并已删除**：使用函数名、特定字符串、固定数据形状、已知输入/结果或对公开用例的整体结构进行专项匹配。即使性能提升也不构成有效实验。

## 2. 统一实验方法

1. 每次只开启一个候选优化，与紧邻的已接受提交比较。
2. 默认先在官方 FPGA 上用 `rdcycle` 对比；明确采用本地 Docker 时，只读取 `starttime/stoptime` 的程序内部时间，并以基线/候选正反顺序重复运行排除调度偏差，不计编译、链接和宿主墙钟时间。
3. 目标热点提速幅度有意义后运行 60 个 `performance`，要求优化模式 60/60 AC；公共语义路径或额外风险改动再运行 140 项 correctness。
4. 140 项 correctness 不启用优化模式。仅当改动影响 `-O0`、前端/语义公共路径或存在额外风险时才运行。
5. 动态指令和 LLVM `generic-ooo` 只作诊断证据；本地模式下 QEMU 的程序内部计时可作为接受证据，但必须重复且超过噪声，不用宿主机 CPU 直接执行 RISC-V 程序。
6. 对静态指令数、load/store、move、mul/div/rem、循环加权指令和必要的动态指令数做汇编级消融。
7. 只有 A 类候选可以作为优化提交推送到当前交付分支；RISC-V 交付分支为 `wz`，AArch64 交付分支为 `wz-arm`。每个优化独立提交、独立消融、独立推送。B/C/D 类代码必须撤回，但实验结论继续在本文留档；E 类必须删除并做合规清理。

2026-07-18 的二维仿射复制与数组维度布局候选由 AI 辅助完成方案对比、独立实现、汇编差异审查和本地消融。技术参考仅为用户提供的公开参赛仓库中的通用数组布局、仿射别名和 store-to-load forwarding 思路；未复制外部实现，未使用测试名、固定规模或已知结果作为触发条件。

2026-07-18 平台复核中，数组维度布局让 `01_mm1/2/3` 从 `1.80/6.31/3.96s` 降到 `1.72/6.01/3.80s`；但仓库所有者随后明确要求在下一提交前关闭该能力，因此实现仍保留供审查，`-O1` 流水线入口已移除，下一平台候选不包含该布局转换。

### 2026-07-21 有符号 bit-accumulate 闭式化、helper 内联与状态提升（待平台判定）

## 2026-07-23 重复幂二有符号除法循环闭式化

- 通用条件：只匹配返回 i32、具有两个 i32 参数和四块规范 CFG 的纯函数。入口进入唯一循环；两个 Phi 分别从零开始单位递增计数，以及从某个形参开始携带商；循环体只能执行 `value = value / D`、计数加一和回边，其中 `D >= 2` 为正二次幂；退出只返回 `value % D`。比较必须是 `counter < count`，所有块和返回均被该结构完整覆盖。
- 变换：令 `D=2^k`。对 `count<=0` 保持原值取余；对 `0<count<ceil(32/k)`，利用重复向零截断除法等价于一次除以 `2^(count*k)`，生成符号偏置加算术右移，再执行同一正除数余数；对 `count>=ceil(32/k)`，任何 i32 商均精确为零。直接调用点不超过 16 个时按形参位置展开同一公式，后续现有 RLE+CSE 可合并相同实参的重复计算；超过代码增长预算时只优化原函数，不展开调用点。
- 合法性：正二次幂除数排除 `INT_MIN/-1`；快速路径保证变量移位位数在 `0..31`，大计数在移位前单独返回零；符号偏置保持负数向零截断。负计数、零计数、`INT_MIN/MAX`、阈值前后和非二次幂结构均有明确语义或 fallback。触发条件不读取源码、函数/变量/块名字面量、固定基数、排序轮数、数组规模、输入或输出。
